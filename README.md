**AeroLab X**

A Python-based aerodynamic lift calculator that calculates lift forces over a range of wind speeds and visualises the results using Matplotlib.

**Description**

AeroLab X is an educational aerodynamic analysis tool built using Python. Users enter air density, wing area and lift coefficient. The program then calculates aerodynamic lift for wind speeds from 1 to 20 m/s using the standard lift equation.

Results are displayed in the terminal and plotted as a graph. The graph can also be saved as a PNG image.

Getting Started

**Dependencies**

-Python 3
-Matplotlib
-Install Matplotlib using:
  |
  ---> python -m pip install matplotlib

**Installing**

Download the project ZIP from this GitHub repository.

Extract it to a folder.

Open a terminal in the extracted folder.

Install the dependencies listed above.

**Executing Program**

Run the terminal version using:

python main.py

Enter the requested air density, wing area and lift coefficient.

The program calculates the lift values and displays a lift-versus-wind-speed graph. It also saves the graph as lift_graph.png.

**Help**

If Matplotlib is missing, install it using the command under Dependencies.

Enter positive numerical inputs when prompted. Invalid or non-positive inputs are not supported.
